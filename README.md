# Innit

**Innit, a part of Knightsbridge Luxury Group.** Gotta be innit to win it.

Online prize-draw platform (website, iPhone and Android apps, back office) for adults 18+ in Great Britain.

- `AGENTS.md`: the full build brief (rules, architecture, phases)
- `CLAUDE.md`: how Claude Code works with the owner
- `docs/INNIT_HANDOVER.md`: the owner's handover (wins over older files)
- `docs/OWNER_TODO.md`: everything we are waiting on the owner for
- `docs/brand/`: brand book (PDF), K emblem, consignor logos
- `docs/design/`: early home-screen drafts (wordmark in them is out of date; follow the brand book)
- `public/prizes/`: sample prize photos for demo draws

Code is added phase by phase; see AGENTS.md section 10.
