# Innit

Gotta be innit to win it.

Online prize-draw platform (website, iPhone and Android apps, admin panel) for adults 18+ in Great Britain.

- `AGENTS.md`: the build brief (rules, architecture, phases)
- `CLAUDE.md`: how Claude Code works with the owner
- `docs/INNIT_HANDOVER.md`: the owner's handover (wins over every other file)
- `docs/OWNER_TODO.md`: everything we are waiting on the owner for
- `docs/brand/`: brand book with the logo specification; the logo itself is built in code (`src/brand/logo/`), see `/brand` on any preview
- `docs/design/`: early home-screen drafts (layout only); full screen set to come
- `public/prizes/`: sample prize photos for demo draws

Code is added phase by phase; see AGENTS.md section 14.
